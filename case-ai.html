AI design workflow: 2.2× handoffs per designer

I gave four designers Git and Claude Code, and each one built tools for their own pain point. With the time saved, we started the company's first research practice.

0.8 → 1.8 handoffs per designer per week Jira and Slack
5 h → 1 click to rebuild a prototype in Figma Figma version history
9% → 50% of design tickets arrive with a clickable prototype Jira

Measured July to October 2026.

Team
4 designers, with an org-wide AI specialist
Product
QuintAce, an AI poker coach on WPT Global
Scope
All design squads

Situation

Design had no coding agents and no repository access

When I joined, engineering had coding agents and its own tooling. Design had ChatGPT. Designers rebuilt every prototype in Figma by hand.

Task

Faster design, with the same four designers

The brief was the same every quarter: faster design, no new headcount, AI as the lever. I owned the tooling gap between design and engineering.

Action

Engineering tools for every designer, in four phases

  1. March We ran weekly sessions on Git, branches and pull requests. First commit on 20 March. All four designers committed within four weeks.
  2. April to June One pain point, one command: bind-tokens, design-qa and find-figma. 9,658 token bindings with zero errors in the first pull request. A brand re-theme in one sprint.
  3. July to August A skill for each phase, discovery to ship. We added a Slack agent for component requests and an Education Hub. 37 tools, three languages. 22 of 35 requests fixed in six weeks.
  4. September to October Prototype-first. A bridge drops the prototype into Figma as library components. 5 tickets built straight from a prototype.

Action

Two decisions that cost something

Skills first, the agent last

In March I built an orchestrator agent before I asked designers what hurt. I shelved it and built their skills first.

Cost: our most demo-able tool.

Prototype-first delivery

Engineering builds from the prototype, and Figma polish runs in parallel.

Cost: Figma is no longer the only source at handoff.

Action

DesignOps: an agent prepares my week

Every ticket follows a Definition of Ready and a Definition of Done. Jira opens design and QA tickets automatically. An agent prepares each fixed meeting:

  • MondaySprint commitments for each designer, and cross-team priorities.
  • TuesdayAction points from the product meetings.
  • ThursdayBacklog planning sync.
  • FridaySprint close and stakeholder updates.

Result

Handoffs per designer went from 0.8 to 1.8 a week

Moved to AI

Variations, hi-fi tweaks, handoff prep, Jira writing, docs.

Stayed with designers

Problem framing, decisions, peer review, talking to players.

The first UX research practice at A5 Labs. We ran the first moderated study: five think-aloud sessions. Players couldn't reach their analysis without help, so we shipped fixes to onboarding and analysis. Synthetic personas built from live player data now give a first read before each handoff.

Learned

Ask designers what hurts before you build

Weekly sessions got the first commits, but a few designers made most of the volume. The team built 37 tools, and now every designer ships from prototypes.
