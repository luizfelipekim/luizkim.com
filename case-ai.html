Situation

Engineering had agents. Design had a chat box.

When I joined, engineering had coding agents and its own tooling. Design had ChatGPT, no repo access, and every prototype was rebuilt in Figma by hand. The ask was to close that gap and get faster, with four designers.

Leverage first, then let designers build for their own pain

  1. March Git and Claude Code for every designer. Weekly sessions on branches and pull requests. First commit 20 March. Four designers committing in four weeks.
  2. April to June One pain point, one command: bind-tokens, design-qa, find-figma. 9,658 token bindings, zero errors, in a first pull request. A brand re-theme in one sprint.
  3. July to August A skill for each phase, discovery to ship. A Slack agent for component requests. An Education Hub. 30 tools, three languages. 22 of 35 requests fixed in six weeks.
  4. September to October Prototype-first: the prototype goes to engineering, and a bridge drops it into Figma as library components. 5 h → 1 click. 5 tickets built straight from a prototype.

Two decisions that cost something

Skills first, the agent last

I built an orchestrator agent in March without asking designers what hurt. I shelved it and inverted the order.

Cost: our most demo-able thing.

Prototype-first delivery

The prototype is what engineering builds from. Figma polish runs in parallel.

Cost: Figma is no longer the only source at handoff.

The week runs itself

Definition of Ready and Done. Jira opens design and QA tickets on its own. A management agent runs my week:

  • MondaySprint commitments to each designer; cross-team priorities.
  • TuesdayAction points from the product meetings.
  • ThursdayBacklog planning sync.
  • FridaySprint close, with stakeholder updates.

Less Figma, more players

Moved to AI

Variations, hi-fi tweaks, handoff prep, Jira writing, docs.

Stayed human

Problem framing, deciding, peer review, talking to players.

Research, from zero. With the capacity freed, the first moderated study ran: five think-alouds that showed players couldn't reach their analysis unassisted. The fixes to onboarding and analysis shipped. Synthetic personas built from live player data now give a first read before each handoff.

Learned

Adoption is the work

One designer wrote 28 of 37 commands. Weekly sessions got the first commit; a few hands made the volume; now every designer ships from prototypes. Ask designers what hurts before building for them.
